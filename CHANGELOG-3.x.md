# Changes for 3.x

This changelog references the relevant changes (bug and security fixes) done to `orchestra/dusk-updater`.

## 3.0.2

Released: 2025-02-18

### Changes

* Support PHP 8.1.
* Use `orchestra/sidekick`.

## 3.0.1

Released: 2025-02-16

### Changes

* Allows Symfony Components versions `^6.2` and `^7.0`.

## 3.0.0

Released: 2025-02-16

### Changes

* Bump minimum supported PHP version to `8.2`+.
* Use `laravel/prompts`.
